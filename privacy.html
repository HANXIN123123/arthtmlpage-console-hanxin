Artmug 운영 콘솔 개인정보 안내

적용일: 2026년 9월 20일

이 콘솔은 사용자가 권한을 가진 Firebase 프로젝트와 Google Drive를 이용해 커미션 메인페이지의 연결 정보와 포트폴리오를 관리하는 도구입니다.

로그인 및 권한

기본 로그인에는 Google 계정의 이메일, 이름, 프로필 사진을 사용합니다. Firebase 프로젝트를 연결할 때 프로젝트 조회·생성 및 데이터 관리 권한을, Drive 이미지 기능을 사용할 때 이 앱으로 사용한 파일에 대한 권한을 별도로 요청합니다. 해당 계정이 접근할 수 없는 프로젝트는 관리할 수 없습니다.

데이터 사용 및 저장

  • Google 액세스 토큰은 브라우저 메모리에서 API 요청에 사용합니다. 콘솔 자체 서버나 브라우저 영구 저장소에 저장하지 않습니다.
  • 마지막 연결 프로젝트 ID를 계정 이메일별로 현재 브라우저의 로컬 저장소에 기억합니다.
  • 페이지 이름·주소, 영상 ID, 사진 링크와 정렬 순서는 사용자가 선택한 Firebase Realtime Database에 저장합니다.
  • 사진·GIF 원본은 사용자가 승인한 Google Drive에 저장합니다. 공개 업로드 또는 공개 버튼 사용 시 해당 파일에 링크 공개 읽기 권한을 설정하여 메인페이지 방문자가 볼 수 있도록 합니다.

외부 서비스 및 공개 범위

Google 계정, Firebase, Google Drive 및 GitHub Pages 호스팅을 이용합니다. 각 서비스의 처리에는 해당 제공자의 정책이 적용됩니다. 공개 포트폴리오 정보는 방문자에게 제공되며, Google 로그인 정보나 액세스 토큰을 방문자에게 공개하지 않습니다. Google API로 얻은 사용자 데이터는 광고, 판매 또는 AI 모델 학습 목적으로 사용하지 않습니다. 콘솔은 연결된 메인페이지의 브라우저 ID 기반 방문 통계를 관리자에게 표시합니다.

해제 및 삭제

콘솔 로그아웃은 현재 세션을 종료합니다. Google 계정의 연결 관리에서 앱 접근 권한을 철회할 수 있습니다. 브라우저 사이트 데이터를 지우면 저장한 프로젝트 정보가 삭제됩니다. 파일과 카테고리를 삭제하면 연결된 Drive 파일 및 카테고리 폴더를 휴지통으로 이동합니다. 기존 페이지와 파일을 공유하므로 양쪽에 영향을 줍니다. 페이지 연결 해제는 포트폴리오 원본을 삭제하지 않습니다.
